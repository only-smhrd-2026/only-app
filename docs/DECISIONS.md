# 기술 결정 기록 (DECISIONS)

하루한장 뼈대(초석)에서 정한 것들을 **이유 / 대안 / 트레이드오프**와 함께 적는다. 발표·면접에서 "왜 이렇게 했나"에 답하는 원천.
결정을 바꾸면 여기 줄을 고치고 PR 에 `D번호` 를 적는다. 원천 문서: 설계안 v1(2026-11-04), 11/5 팀 회의.

## 0. 전제

React PWA(TypeScript) / Python 3.12 + FastAPI / PostgreSQL 16(테이블 18) / Cloudflare R2 / APScheduler / Claude Haiku 5.5 / 그림 Workers AI FLUX.2 klein 4B(D37) / STT·TTS 는 1안(D35), 11/15 비교 후 확정 / EC2 + Docker Compose + Caddy. 기본값은 전부 mock(팀원 PC 에 키 불필요). 실제 연결은 홍진성 PC: Claude·그림(11/6), STT·TTS 는 AI-02(11/9 주). 구현 11/9~12/4, 중간 점검 11/22.

**11/5 팀 회의 결정**: 초석 범위는 원안(음성 왕복 걷는 해골 + VoiceSession + 실제 화면 6개 포함). 공통 사진(계절·명절 20장)은 MVP 제외(테이블 없음, FR-ME-005 80/20 문구 수정). 테이블 수정 S1~S15 를 `db/schema.sql` 에 지금 반영.
