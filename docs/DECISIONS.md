하루한장 뼈대(초석)에서 정한 것들을 **이유 / 대안 / 트레이드오프**와 함께 적는다. 발표·면접에서 "왜 이렇게 했나"에 답하는 원천.

## 0. 전제

React PWA(TypeScript) / Python 3.12 + FastAPI / PostgreSQL 16(테이블 12, D38) / Cloudflare R2 / APScheduler / Claude Haiku 5.5 / 그림 Workers AI FLUX.2 klein 4B(D37) / STT·TTS 는 1안(D35), 11/17 비교(TEST-01 #17) 후 확정 / EC2 서울 + Docker Compose + Caddy, 도메인 DuckDNS(D41). 기본값은 전부 mock(팀원 PC 에 키 불필요). 실제 연결은 홍진성 PC: Claude·그림(11/6), STT·TTS(11/10, D46). 구현 11/9~12/4, 중간 점검 11/22.
